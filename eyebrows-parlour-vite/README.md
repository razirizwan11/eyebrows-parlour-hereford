## 🚀 Quick Start

```bash
# 1. Install dependencies
npm install

# 2. Start development server
npm run dev

# 3. Open http://localhost:5173
```

## 📦 Build for Production

```bash
npm run build
```

Output goes to `dist/` — ready to deploy on **Netlify**, **Vercel**, or any static host.
